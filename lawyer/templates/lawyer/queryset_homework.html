تطبيق دوال QuerySet السبع المعتمدة

تم تجميع كافة الاستعلامات وتطبيقات QuerySet المعتمدة في دالة واحدة (homework_queryset_demo) في ملف lawyer/views.py مع توثيق عربي كامل لتسهيل لقطة الشاشة (Screenshot) للدكتورة.

انتقل لطرق الفورم الثلاث
1. دالة filter() تصفية النتائج

الهدف: تصفية المحامين الذيم تزيد سنوات خبرتهم عن سنتين (experience_years__gt=2).

Lawyer.objects.filter(experience_years__gt=2)
النتيجة الحية ({{ qs_filter.count }} عناصر):
    {% for lawyer in qs_filter %}
  • {{ lawyer.name }} (خبرة: {{ lawyer.experience_years }} سنوات)
    • {% empty %}
  • لا يوجد عناصر طابقت الشرط
    • {% endfor %}
2. دالة exclude() استبعاد العناصر

الهدف: استبعاد المحامين الذين لا يملكون تخصصاً مدخلاً.

Lawyer.objects.exclude(specialization="")
النتيجة الحية ({{ qs_exclude.count }} عناصر):
    {% for lawyer in qs_exclude %}
  • {{ lawyer.name }} - تخصص: {{ lawyer.specialization }}
    • {% empty %}
  • جميع العناصر مستبعدة
    • {% endfor %}
3. دالة order_by() ترتيب النتائج

الهدف: ترتيب السجلات تنازلياً حسب سنوات الخبرة (من الأعلى إلى الأقل).

Lawyer.objects.order_by('-experience_years')
المرتبون تنازلياً:
    {% for lawyer in qs_order_by %}
  1. {{ lawyer.name }} ({{ lawyer.experience_years }} سنوات)
    2. {% endfor %}
4. دالة select_related() 1-to-1 JOIN Optimization

الهدف: ربط المحامي ببطاقته المكتبية (One-to-One) وحسابه باستعلام واحد.

Lawyer.objects.select_related('office_card', 'user')
بيانات العلاقات (1-to-1):
    {% for lawyer in qs_select_related %}
  • {{ lawyer.name }} - بطاقة: {{ lawyer.office_card.card_number|default:"غير صادرة" }} (قاعة: {{ lawyer.office_card.office_room|default:"-" }})
    • {% endfor %}
5. دالة prefetch_related() Many-to-Many Optimization

الهدف: تحسين استعلام علاقة (كثير إلى كثير) مع جدول التخصصات الفرعية.

Lawyer.objects.prefetch_related('specializations')
التخصصات الفرعية المرتبطة (Many-to-Many):
    {% for lawyer in qs_prefetch_related %}
  • {{ lawyer.name }}: {% for spec in lawyer.specializations.all %} {{ spec.name }} {% empty %} لا يوجد تخصصات فرعية {% endfor %}
    • {% endfor %}
6. دالة annotate() إضافة حقل تجميعي

الهدف: حساب عدد القضايا المسندة لكل محام ديناميكياً باستخدام Count.

Lawyer.objects.annotate(total_cases=Count('caserequest'))
عدد القضايا لكل محامٍ:
    {% for lawyer in qs_annotate %}
  • {{ lawyer.name }}: {{ lawyer.total_cases }} قضايا
    • {% endfor %}
7. دالة aggregate() حساب إحصائيات إجمالية

الهدف: حساب المتوسط الإجمالي للخبرة، وأعلى وأدنى خبرة.

Lawyer.objects.aggregate(Avg('experience_years'), Max(...))
متوسط الخبرة: {{ qs_aggregate.avg_experience|floatformat:1 }} سنوات
أعلى سنوات خبرة: {{ qs_aggregate.max_experience }} سنوات
أقل سنوات خبرة: {{ qs_aggregate.min_experience }} سنوات
8, 9, 10. دوال values() / count() / exists() دوال سريعة

الهدف: استخراج القواميس، والعد الفعلي، والتحقق السريع من الوجود.

values('name', 'specialization') | count() | exists()

كود Python للدوال السبع (جاهز لـ Screenshot)

هذا هو الكود البرمجي المكتوب في lawyer/views.py تحت اسم homework_queryset_demo:

def homework_queryset_demo(request):
    # 1. filter() - تصفية المحامين ذوي الخبرة أكثر من سنتين
    qs_filter = Lawyer.objects.filter(experience_years__gt=2)

    # 2. exclude() - استبعاد المحامين بدون تخصص
    qs_exclude = Lawyer.objects.exclude(specialization="")

    # 3. order_by() - ترتيب المحامين تنازلياً حسب الخبرة
    qs_order_by = Lawyer.objects.order_by('-experience_years')

    # 4. select_related() - تحسين استعلام علاقة (One-to-One)
    qs_select_related = Lawyer.objects.select_related('office_card', 'user').all()

    # 5. prefetch_related() - تحسين استعلام علاقة (Many-to-Many)
    qs_prefetch_related = Lawyer.objects.prefetch_related('specializations').all()

    # 6. annotate() - حساب عدد القضايا لكل محامٍ
    qs_annotate = Lawyer.objects.annotate(total_cases=Count('caserequest'))

    # 7. aggregate() - حساب متوسط وأعلى وأدنى سنوات الخبرة
    qs_aggregate = Lawyer.objects.aggregate(
        avg_experience=Avg('experience_years'),
        max_experience=Max('experience_years'),
        min_experience=Min('experience_years')
    )

    # 8. values() - استخراج حقول محددة فقط
    qs_values = Lawyer.objects.values('id', 'name', 'specialization')

    # 9. count() & 10. exists()
    total_lawyers_count = Lawyer.objects.count()
    has_lawyers = Lawyer.objects.exists()
